# Politique de confidentialité de MEOWZic

*Dernière mise à jour : 6 novembre 2026*

MEOWZic est un bot Discord de musique géré à titre personnel par **emika._5 ou clementchap9@gmail.com**. Cette page explique quelles informations le bot utilise.

## 1. Informations utilisées
Quand tu utilises une commande du bot (par exemple `/play`), il traite :
- l'**identifiant du serveur** et du **salon** où la commande est utilisée ;
- ton **nom d'affichage** sur le serveur, pour écrire « Ajouté par… » dans la file d'attente ;
- le **texte ou le lien** que tu as demandé (titre, lien YouTube ou lien Spotify).

Le bot **ne lit pas tes messages** : il répond seulement aux commandes slash. Il ne demande ni ton email, ni ton mot de passe, ni aucune information de paiement.

## 2. Stockage
- La file d'attente (titre, lien ou recherche, nom d'affichage) est enregistrée dans un **fichier sur l'ordinateur** qui fait tourner le bot.
- La commande `/stop` vide cette file.
- Aucune base de données externe n'est utilisée.
- Tes informations ne sont **ni vendues, ni partagées, ni utilisées pour de la publicité**.

## 3. Services tiers
Pour fonctionner, le bot envoie des requêtes à d'autres services :
- **Discord**, pour recevoir les commandes et diffuser l'audio ;
- **YouTube**, pour rechercher et lire les musiques demandées ;
- **Spotify** (page publique), uniquement pour lire le titre et l'artiste d'un lien Spotify.

Ces services ont leurs propres politiques de confidentialité.

## 4. Conservation
Les informations de la file d'attente sont gardées le temps nécessaire à la lecture, puis supprimées quand la file est vidée (musique terminée ou `/stop`).

## 5. Tes droits
Tu peux demander à tout moment la suppression des informations qui te concernent en me contactant (voir ci-dessous).
